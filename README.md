# Lost & Found

A campus-based Lost & Found web application that helps students report lost items, post found items, and find potential matches.

## Features

- Report Lost Items
- Report Found Items
- Search Lost & Found Items
- Item Matching
- Owner Verification
- Dashboard
- Image Upload
- Campus Location & Date Details

## Tech Stack

- React
- JavaScript
- CSS
- Firebase
- Vite

## Project Purpose

The goal of this project is to provide a centralized platform for university students to report and recover lost items easily.
